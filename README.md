# Продажи декоративных птиц в Online Retail

В [ноутбуке](dz1.ipynb) разобраны продажи товара **84879 - ASSORTED COLOUR BIRD ORNAMENT** с 1 декабря 2010 по 9 декабря 2011 года. За этот период объём покупок составил 36 461 штуку, объём возвратов - 80 штук. Возврат вычитается в день его регистрации. Списание 160 повреждённых штук в продажи не входит. Полные повторы сохранены: время общее для накладной, а одинаковый товар мог быть внесён отдельными позициями. Без номера позиции нельзя подтвердить, что строка продублирована по ошибке.

## Что видно в данных

- В пять дней магазин регистрировал операции с другими товарами, а покупок и возвратов этого товара не было. Ещё за 69 дней нет записей по всему магазину. В эту группу попали все субботы.
- Медиана дневных продаж - 56 штук, среднее - 97,45. Порог в 266 штук по правилу 1,5 IQR превысили 27 из 373 полных дней (7,2%). Самый крупный заказ объясняет 2 880 из 3 359 штук за 4 августа. Такие пики сохранены. У недель и месяцев свои пороги, за ними оказались две недели из 52 и два месяца из 12.
- Продажи зависят от дня недели. Медиана четверга - 91 штука, воскресенья - 42. В разложении STL виден рост общего уровня после зимнего спада. Один крупный августовский заказ выделяется даже с учётом этого роста и дня недели. Для проверки годовой сезонности данных мало.
- Для исходных дней и недель тест KPSS отвергает стационарность вокруг постоянного уровня. Поэтому дневные продажи после логарифмирования были сопоставлены с тем же днём прошлой недели, а недельные - с предыдущей неделей. После преобразований результаты ADF и KPSS согласуются со стационарностью по уровню. Разброс дневных разностей всё ещё зависит от дня недели. По субботам все они равны нулю. Вывод по месяцам менее надёжен - есть всего 12 полных месяцев и 11 разностей.

## Как запустить

Для запуска в Python 3.11 необходимо установить зависимости командой `python -m pip install -r requirements.txt`. Затем требуется открыть `dz1.ipynb` в Jupyter или VS Code и выполнить ячейки сверху вниз. Данные уже лежат в папке `data`. CSV сжат без изменения строк.
